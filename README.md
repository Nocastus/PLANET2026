# ISHTAR

An additive harmonic phase-distortion synthesiser - a VST3 plugin and standalone app for Windows.

ISHTAR is a cross between a digital phase-distortion synth (in the spirit of the Yamaha DX7) and an
additive tonewheel organ (in the spirit of the Hammond). It is good at pads, plucked sounds, and
thickeners that help glue a mix together, and it easily makes organ and electric-piano voices unlike
anything a real electromechanical instrument can produce. It does not try to sound like an analogue
subtractive synth.

Built with [JUCE](https://juce.com).

## Status

In beta. Windows VST3 and standalone.
